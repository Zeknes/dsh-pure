## 签名

上述 APK 是 release 编译、Android Debug 证书签名的测试包，签名算法 RSA 2048，证书 SHA-256 `5fc40a6b251d553140e10d968fbf7d04f96ce18a0dacb72435d072a69bed847f`。构建机 ROG 的默认 Android 调试签名文件路径为 `/home/zek/.android/debug.keystore`；后续覆盖安装必须由构建工具使用同一密钥，构建后再次核对证书指纹。未确认该密钥已安全备份；遗失后不能保证覆盖更新。不要将密钥文件、密码或配置提交到仓库。构建机的调试密钥文件权限已由 0644 收紧为 0600；勿将其视为正式发行密钥。

## 匿名统计删除

App 原匿名使用统计的设备信息、账本、发送、前后台调度及开关已移除；升级启动时清理旧 `usage_stats_` 偏好。本地 token、费用和诊断不属于该上报链。worker 源码移除 `/api/usage/v1` 及专用统计绑定、报表，未部署线上服务；下载和更新检查计数仍保留。引擎对 session telemetry、桌面产品遥测及客户端产品分析的采集和发送实现打补丁移除，未删除用户主动使用的本地功能。Google ML Kit 是独立 SDK，仍可能发送其自身统计，不受本次删除控制。DSH 官方模型请求的额外 `dsh_session_log` 诊断字段已移除；普通模型消息与工具上下文保留。源码不再注册默认 session/product 遥测行；防止旧配置恢复上报的兼容服务已移除其 reporter 和采集监听。

## 本机指令更新

App 管理的本机 AGENTS 指令从实际 rootfs 的 os-release 获取系统名称，未知时不猜版本，并要求运行时检查 Node 版本；区分 Android 宿主与 PRoot / 直接启动，不改远程主机指令。已授权的普通可逆任务直接执行、遇错先自行诊断，同时保留对外或不可逆操作、凭据与系统授权边界。新版以 BEGIN/END 标记管理段落；无标记的用户文件不覆盖，已知旧版模板可迁移，无法确认的旧版混合内容保留并追加新版段落。已有旧测试 APK 不含本轮改动。

## 权限边界

个人版在本地新对话默认启用自动执行命令：设置加载后，未保存用户选择时采用 `danger-full-access` 预设；已保存的关闭选择优先。该预设采用完全文件权限及 `never` 审批策略：无需审批的操作直接执行，真正需要审批的请求会被拒绝，并非自动批准。安全模式及远程主机不套用该默认，用户可在设置中调整。子任务按引擎现有继承规则执行，不能自行扩大权限。该默认依赖 App 创建会话时应用预设；应用失败时现有代码会回退引擎默认，不能保证所有启动路径及后台子任务均为完全权限。隔离真实 DSH 0.2.2-rc.1 检查中，父会话和子任务均在完全权限下成功读写工作区外的临时文件；这不代表 Android 真机已验收。

Android 的存储、通知、无障碍及其他系统权限仍需系统正常授权；没有静默授予，也不改变认证、SSH 主机密钥校验、外部验证码或操作系统保护。
